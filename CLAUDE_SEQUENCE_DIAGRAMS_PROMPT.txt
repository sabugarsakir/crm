DETAILED ROLE SEQUENCES (BASED ON THE REAL ESTATE CRM CODEBASE):

================================================================================
1. ADMIN SEQUENCE DIAGRAM (System Administrator)
================================================================================
Lifelines:
• Lifeline 1: Admin (Actor)
• Lifeline 2: CRM System (React Frontend & Node.js Express Backend)
• Lifeline 3: Database (MongoDB Document Database)

Message Sequence:
1. [Login Flow]
   - Admin -> CRM System: Login With Admin Credentials
   - CRM System -> Database: Validate Admin (email, password hash)
   - Database --> CRM System: Valid (User Document & Role: "Admin")
   - CRM System --> Admin: Login Successfully & Admin Dashboard Displayed

2. [Manage Users & Roles Flow]
   - Admin -> CRM System: Create New User Account (Name, Email, Number, Role, Location)
   - CRM System -> Database: Save User Record (Bcrypt Password Hashing)
   - Database --> CRM System: User Record Created Successfully
   - CRM System --> Admin: User Account Created Confirmation Shown

3. [Create & Configure Project Flow]
   - Admin -> CRM System: Create Project (Name, Description, Location, Mandate Status)
   - CRM System -> Database: Save Project Data in projects_collection
   - Database --> CRM System: Project Saved Successfully
   - CRM System --> Admin: Project Created Successfully

4. [Assign Agents to Projects Flow]
   - Admin -> CRM System: Assign Sales Agents to Project
   - CRM System -> Database: Update assignedAgents ObjectId Array in Project
   - Database --> CRM System: Project Agent Mapping Updated
   - CRM System --> Admin: Agents Assigned Successfully Notification

5. [Verify Channel Partner Flow]
   - Admin -> CRM System: Verify Channel Partner Application (Check RERA/PAN/GST)
   - CRM System -> Database: Set isVerified: true & Generate User Account
   - Database --> CRM System: CP Account Activated & Updated
   - CRM System --> Admin: Partner Verified & Login Credentials Emailed
